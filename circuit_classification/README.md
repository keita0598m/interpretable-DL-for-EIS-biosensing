# 等価回路分類

EIS（電気化学インピーダンス法）のナイキスト線図から、データがどの等価回路
（C1〜C4）に従うかを分類するモデル。

潜在空間を2次元に絞った VAE に分類器を並列接続し、再構築誤差・KLダイバー
ジェンス・分類誤差を同時に最小化する。潜在空間を低次元に保つことで、学習後
そのまま散布図として可視化・解釈できる。

## 対象回路

| 回路 | 構成 | パラメータ |
|---|---|---|
| C1 | Rs + (R1 // CPE1) | Rs, R1, Q1 |
| C2 | Rs + (R1 // CPE1) + (R2 // CPE2) | Rs, R1, Q1, R2, Q2 |
| C3 | Rs + [(R1 + Warburg) // CPE1] | Rs, R1, Q1, σ |
| C4 | Rs + (R1 // CPE1) + [(R2 + Warburg) // CPE2] | Rs, R1, Q1, R2, Q2, σ |

## 構成

```
./
├── config.py     # 回路定義・実験設定
├── dataset.py     # 回路インピーダンスのシミュレーションによるデータセット生成
├── model.py         # VAE + 分類器
├── train.py           # 学習ループ
├── evaluate.py           # 評価指標・可視化
└── main.py                 # 実行エントリーポイント
```

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
python main.py
python main.py --epochs 300 --latent-dim 2
```

学習後、以下を出力します。

- テスト精度・分類レポート
- 潜在空間の散布図（回路ごとに色分け）
- 混同行列
- 学習損失の推移（再構築誤差 / KL / 分類誤差）
- 潜在空間の格子点をデコードしたナイキスト線図一覧
- 潜在空間上の分類マップ・信頼度マップ
- 潜在空間上の回路パラメータ分布マップ

## 主要なオプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `--epochs` | エポック数 | `300` |
| `--latent-dim` | 潜在空間の次元数 | `2` |
| `--input-mode` | `nyquist` または `bode` | `nyquist` |
| `--include-freq` | 入力に周波数チャンネルを含める | `False` |
