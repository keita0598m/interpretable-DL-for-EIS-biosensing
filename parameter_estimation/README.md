# 回路パラメータ推定

EIS（電気化学インピーダンス法）のナイキスト線図から、等価回路（C1/C2/C3）の
回路定数（Rs, R1, Q1, R2, Q2, σ など）を推定するモデル。

Encoder に1次元CNN（VGG風の畳み込み構成）を用いた VAE をベースとし、
潜在空間からパラメータ推定ヘッドを分岐させている。学習には物理情報付き損失
（PIML: 推定パラメータから再構築したインピーダンスと真値との誤差）を加え、
パラメータ単体の誤差だけでは捉えきれない物理的な整合性を補っている。

## 構成

```
./
├── config.py     # 回路定義・実験設定
├── dataset.py     # LHSサンプリングによるデータセット生成
├── model.py       # 1D CNN VAE + パラメータ推定ヘッド
├── losses.py       # 物理情報付き損失（PIML）
├── train.py         # 学習ループ
├── evaluate.py       # 評価指標・可視化
└── main.py             # 実行エントリーポイント
```

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
# C1, C2, C3 をまとめて学習（デフォルト）
python main.py

# 回路・エポック数・潜在空間の次元数を指定
python main.py --circuits C3 --epochs 10000 --latent-dim 4
```

学習後、各回路について以下を出力します。

- 学習損失の推移（再構築誤差 / KL / パラメータ誤差 / PIML誤差）
- パラメータごとの決定係数（R2）
- True vs Predicted 散布図
- 潜在空間の可視化（各パラメータでカラーマップ）

## 主要なオプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `--circuits` | 学習する回路（複数指定可） | `C1 C2 C3` |
| `--epochs` | エポック数 | `10000` |
| `--latent-dim` | 潜在空間の次元数 | `4` |
| `--samples` | 回路あたりのサンプル数 | `30000` |
